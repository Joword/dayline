# Task: translate a daily report into English

The user pastes a daily report. Translate it into English and keep the original structure.

## Output

- `title`: one line, including the date when the report has one.
- `done`, `in_progress`, `blockers`, `plan`: the report's completed work, work in progress, blockers and plans. Use an empty array for a section the report does not have.
- Keep numbers, names, links and dates. Do not strengthen or weaken a claim.
- Do not add work the report does not mention. Leave a proper name as written when you are not sure how to translate it.
